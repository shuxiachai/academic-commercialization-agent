# Read [AGENTS.md](AGENTS.md)

The project instructions live there, in one copy, because `AGENTS.md` is the
filename the other assistants load by convention. Duplicating them here would
just create two versions to keep in step, and the one that drifts is always the
one nobody is reading at the time.

`AGENTS.md` covers the commands, the conventions, where each decision's
reasoning is kept, and — the section worth reading before proposing anything —
the changes that have already been tried, measured, and rejected on data.

Vendor CrewAI reference: `docs/crewai-reference.md`.
