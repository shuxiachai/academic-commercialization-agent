RQ01 intentionally discarded the completed upstream POST acknowledgement.
The browser showed uncertainty, reloaded without another POST or automatic GET,
and recovered the result only after a fresh synthetic code and explicit receipt
GET. RQ02 also exercised refresh and explicit replay. Each case retained exactly
one callback, one native reservation/finish pair and one temporary daily-paid
admission. Replay did not cause another selection, native request or charge.

All fourteen HTTP fields were checked at the actual response boundary. Original
and replay results matched the bound saved snapshot. The browser displayed exact
inert text, including CRLF, whitespace, a literal HTML marker and Unicode; it did
not interpret the marker as markup. Both source identities were unchanged before
and after execution. Physical threads and paid-operation slots were zero after
drain. These observations do not prove provider-level exactly-once execution or
survival of a process crash or disk loss.

The provider reported the authorized model string with coherent usage on both
requests. That identity check is not attestation of backend model weights.
Chromium was `151.0.7922.34`, Playwright `1.62.0`; package/runtime observations
are not installed-binary attestation. Case elapsed times were 15.297 and 14.484
seconds; whole-batch elapsed time was 30.328 seconds. They include local identity,
browser, delivery, drain and case-publication work, not isolated provider latency

## Interpretation and remaining gate

This closes one narrow gap: a real model choice can cross the paid receipt and
browser recovery seams without a second selection after a lost acknowledgement.
The model chose a source or declined; code performed the read and delivered
saved text. It did not generate a supported answer or validate scientific claims.

The cases are two easy fictional development controls with LLM-reviewed
references, not human gold, unseen tasks or observed user benefit. Declining RQ02
means no title fits this small catalog, not that methane-calibration literature
does not exist. Source text never went to Qwen, so the model did not judge it.

The fixed-case adapter is not a general configured provider factory. A public
feature still needs explicit release scope, useful real saved-report evaluation
under its own data boundary, and truthful client-visible accounting. The
production evidence-gap pipeline remains zero-call shadow mode. Existing source
viewing remains the no-model alternative; this result establishes no advantage
over it. No closed semantic-relation experiment is reopened by this success.
