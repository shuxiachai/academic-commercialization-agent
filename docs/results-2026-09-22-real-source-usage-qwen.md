## Observed result

Four sequential native requests to the exact `qwen3.5-plus` transport completed.
All four passed the mechanical delivery/accounting gates and matched the frozen,
fallible LLM title-location reference sets. Three produced a code-owned saved
excerpt; one explicitly declined because no catalog title fit the question.
The set-valued reference remained a set rather than being retrospectively
changed to whichever source the model chose.

Each case had one selector entry, one native request and one paid admission.
There were three execution source reads. The four subsequent same-receipt GETs
added four delivery snapshot reads and three delivery source reads, not another
selector invocation, native request or paid admission. These are distinct
execution/delivery counters, not a claim that only three filesystem reads occurred.

POST and GET preserved the exact saved result and operation-specific accounting.
Returned saved text matched the frozen snapshot. Each native ledger had exactly
one reserved/finished pair, a matching complete request-body hash, an authorized
reported model, complete reported usage and no accounting fault. All four
accounting projections were sealed with a complete native journal.

The native request's dynamic content was only the frozen question and visible
source IDs/titles. Exact wire checks matched the previously admitted bodies.
Full reports, saved excerpts, reference labels, original run metadata and
credentials were not prompt content. Excerpt retrieval occurred locally after
selection; no second model request generated or judged a research answer.

Original packet bytes remained unchanged. Raw inputs, labels, requests, source
text, receipts, journals, review output and private input identities remain local;
this public record contains only qualified aggregate observations.

## What this establishes, and what it does not

This is an observed **native selection -> local saved-source read -> isolated
ASGI POST/GET -> durable usage/accounting** path on four development cases.
It is not merely a scripted provider response. It is also not a native real-
browser journey: the shipped renderer has separate intercepted Chromium tests,
and combining those observations must not imply a browser run that did not occur.

All POST acknowledgements were received. Native lost-acknowledgement, timeout,
cancellation, unknown-usage and failure recovery were not observed in this batch;
their existing synthetic controls remain separate evidence. Normal GET without
redispatch does not turn into proof of every interrupted-request scenario.

The [independent reference review](results-2026-09-22-real-source-usage-reference-review.md)
used one fresh LLM context and title metadata only. Therefore 4/4 reference
agreement is not human expert gold, general accuracy, verified article type,
scientific correctness, claim support or unseen-data success. The reports were
historical consumed evidence, and the questions were development controls.

The unchanged assisted-keyword baseline already covered all three positive
reference cases, including an ambiguous result set. This run establishes a
native natural-language selection path, not superiority over that baseline,
time saved, user adoption or improved commercialization decisions.
