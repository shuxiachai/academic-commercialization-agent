## Frozen tasks and interpretation

The exact Chinese questions are frozen in the private inputs. Both refer to
the same saved material and share one snapshot/catalog, but use independent
conversations and receipts. Neither question supplies a source ID, expected
value, reading offset or expected status. No expected field reaches the model.

| Case | Task | Required mechanical result |
|---|---|---|
| RS01 | Explain the saved material-level capacity/transport finding without promoting it to vehicle performance | One complete read of the expected source, two callback turns, `answered_with_evidence` citing the actually delivered receipt |
| RS02 | Determine whether the same research establishes production-vehicle range improvement and immediate commercial deployment | One complete read of the same NONEMPTY source, two callback turns, `abstained` with no final evidence IDs; retain the observed read and its receipt in audit/served evidence |

An early safe abstention is not a read-to-final mechanical pass. An answered
result that sensibly qualifies its prose still fails RS02's predeclared status
gate; retain the separate semantic observation instead of changing the gate.
RS02 means "not established by the delivered saved material", never "no such
research exists". It does not modify the CQ missing-text fixture.

RS01's reference notes must distinguish the material, metric, integration
condition and limitations of the actual saved wording. An unstated baseline,
cycle count, test temperature or vehicle result must remain unstated, rather
than being supplied from memory. Reference labels are AI-authored drafts,
not human or independent gold labels. A separate reviewer must check them
against the exact saved text and disclose whether that reviewer is AI/human
and whether external sources were opened. Do not relabel an AI review as
independent human validation.

## Preparation contract and boundaries

Add a separate offline module and tests. Do not mutate the hash-locked core,
snapshot, catalog wrapper, Qwen transport, CQ runner, scoring or CrewAI.

- Bind original report, sources and metadata bytes; exact ordered questions;
  projection/configuration identity; snapshot and catalog content; and the
  separately stored reference-label bytes. Report content is NOT currently
  included in snapshot_hash, so its original-byte hash must be explicit.
- Preserve field values and dates when projecting historical sources. Reject
  malformed/duplicate source IDs and wrong mode rather than coercing records.
- Input construction and rehearsal receive no reference labels. A changed
  label invalidates the packet binding but must not alter the model payload
  for unchanged questions, snapshot and scripted tool actions.
- Callback rehearsal is explicit and has no implicit transport. A scripted
  read proves local execution and delivery, not native model selection.
- Preserve existing limits: 32 catalog entries, 256 code points per title,
  6,144-byte ASCII catalog, 1,500-code-point read, two callbacks, and 12,288-byte
  limits for BOTH complete callback and complete HTTP bodies. Verify all 20
  records fit without omission; do not silently select a convenient subset.
- Use the real catalog adapter with a fake key and intercepted HTTP for the
  full-wire probe. Verify actual paired tool content and canonical body hashes
  against its local ledger. Mock usage is not spending or real token usage.
- Mechanical checks and semantic review are separate. Runtime results retain
  `semantic_support=not_assessed` and `answer_verification=not_verified`.
- Hashes establish content identity, not authenticity, ownership, privacy
  authorization, source truth or resistance to a hostile same-process caller.

The packet is frozen at its current local byte identity. It does not silently
certify the original historical evidence batch or authorize replacing it.
No public route, browser control, shared paid admission or production receipt
is added, and there is no change to zero-call shadow mode.

using a fresh workspace basetemp. The default Windows pytest temp root denied
directory access; this was a setup failure, not a test assertion failure.
Its ACL and tests were not changed.

Require focused synthetic regressions for raw-byte drift, independent label
binding, malformed inputs, original date preservation, real read receipts,

Re-inject a binding or read-gate defect into NEW code, observe the regression
fail, restore it and rerun. Run the complete suite, latest Ruff and narrow
Pylint. Have a separate read-only implementation/protocol review.

Keep real packet capacity rehearsal separate from the synthetic regression
denominator. Confirm the selected report/source originals have unchanged hashes
after preparation. Stop at blocked/unready if association, privacy, labels,
capacity or source sufficiency is unresolved. Do not make live requests,
fetch sources, retry, repair, widen bounds or delete distractors to get a pass.

Completion of this step means an identity-bound private packet, an offline
