## Reuse and data boundary

Reuse the existing `LocatorQwenTransport`, exact `LocatorQwenLedger`, catalog
builder and local saved-source reader without modifying their frozen files.
The production accounted wrapper delegates selection to this same transport.
This protocol does not exercise its HTTP receipts, billing admission, browser,
deployment configuration or real-user authorization; do not claim those results.

Only the frozen question and complete ID/title catalog, including its derived
counts, enter each request. Keep saved excerpts, report bodies, metadata,
reference labels and keyword queries out of provider prompt content. Bind the
entire approved request-preview file and require exact serialized wire equality,
not merely a matching source ID, field list or callback count. Preserve model,
endpoint, non-thinking mode, tool schema, token/byte limits and Chinese encoding.

The private packet also binds the complete saved-source bytes and the separate
review evidence used for local delivery checks and post-response comparison.
Those inputs stay local. Public code accepts explicit expected identities but
does not hardcode or print private packet/preview hashes. Identity checks bind
the final committed implementation, actual source/dependency closure, tests,
this protocol and the lockfile; the preparation's earlier commit is not a
substitute for the execution commit.

## Admission and stopping

Default CLI use is identity-only: no key discovery, provider/store construction,
new output or network dispatch. Native entry requires the explicit protocol
acknowledgment, expected code/packet/preview identities and the applicable
operator data/budget authorization after tests, independent review and green CI.
Flags and a self-authored manifest do not independently grant that authority.

Use one fixed new output directory. Reserve the entire four-request batch by
an exclusive durable claim before looking up the process's `DASHSCOPE_API_KEY`.
The runner never reads `.env` or falls back to another credential. Any separately
authorized single-key injection is outside this runner. Existing, partial or
unresolved outputs remain occupied; deleting them is not permission to rerun.

At most four sequential requests, one per case, with a USD 0.05 soft stopping
line. Four unchanged conservative reservations total USD 0.044597248. This is
a frozen engineering estimate, not a current retail quote, invoice or hard
price guarantee. An operator must accept possible small in-flight excess.
No refunds or lower reported usage buy additional requests. A fresh per-case
ledger never resets the aggregate allowance.

No retries, redirects, repair, fallback, recovery, supplementary searches,
additional paid judging or production activation are allowed. Check identity
before and after each request. Reconcile actual wire, durable reservation and
finish events, exact model, complete reported usage, selected ID and original
saved-text delivery. A mechanical fault, unknown accounting, refusal, budget
fault, persistence failure or frozen-reference mismatch stops later cases;
unrun rows stay explicitly `not_run`. A selector exception converted to a
locator result is still failure, never success through a non-raising API.
