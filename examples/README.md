# Example Reports

Six complete commercialization assessment reports generated by the agent.
Each report synthesises academic papers, patents, and market intelligence into a
structured analysis with technology maturity evaluation, patent landscape mapping,
and strategic recommendations.

- **2026-11-08:** five live runs from the command line on the current pipeline
  (`14a2097` and `9bd948c`, which differ only in documents) with
  `deepseek-v4-pro`, kept verbatim as the writer and reviewer left them. They
  are five of the ten held-out topics of that day's spot check
  ([protocol](../docs/prereg-2026-11-08-heldout-spot-check-deepseek-v4-pro.md),
  [result](../docs/results-2026-11-08-heldout-spot-check-deepseek-v4-pro.md),
  [part B](../docs/results-2026-11-08-heldout-spot-check-deepseek-v4-pro-b.md)),
  chosen for a spread of maturity and one Chinese input. A run from the command
  line carries no decision context, so these reports have no applicability
  paragraph at the top.
- **2026-10-21:** one production run from pipeline `a8cc424` with `qwen3.8-27b`,
  *Hyperloop*, kept verbatim: the one-word input, and the one report here that
  carries the code-inserted applicability paragraph a web run gets. The web
  reader shows that paragraph as plain text without its HTML comment marker,
  as the run page does.

None of them is a measure of model accuracy or an up-to-date market assessment,
and their citations have not been re-verified. A reader who checked them found
only what the reviewer notes at the end of each report already show: wording
the reviewer tightened, a duplicated citation cluster, a source carried twice
under two addresses, and, in the space-based solar power report, market
evidence that leans on one small company's press releases, which the report
itself says.

Beside each of the six is the scorecard its run wrote, `<name>.scores.json`:
the run's `commercialization_scores.json` as written (for *Hyperloop*, as the
production deployment still serves it for that run). The scores quoted below
are read from those files. The web reader builds its decision brief and its
scorecard from them, with the functions a run's own page uses; a sample keeps
neither the run's checks nor its source registry, so the lines those would add
to the brief are absent there, and the page says so.

All six can also be read in the web app at `/samples`, with no access code or
API key. That list is the allowlist in `api/samples.py`; a file added here does
not appear there until it is added to the list. Three July 2026 reports from
pipeline `9673a83` (`solid-state-batteries-ev.md`, `perovskite-solar-cells-bipv.md`,
`car-t-therapy-solid-tumors.md`) and the earlier Chinese solid-state batteries
run stay in this folder because frozen comparisons read them by path; they are
no longer listed on the page.

## Reports

### [Continuous glucose monitoring for diabetes](continuous-glucose-monitoring.md)

| | |
|---|---|
| **Topic** | continuous glucose monitoring for diabetes (2026-11-08, `deepseek-v4-pro`) |
| **Scores** | TRL 9 (expected range 8–9) · overall 74.0 / 100 |
| **Sources** | 8 academic papers · 8 patents · 8 market sources |

**Headline finding:** A standard of care for type 1 diabetes with moderate-certainty
evidence of a modest HbA1c reduction in type 2; a patent thicket around device
architecture held by Abbott, Medtronic and Roche; market estimates that differ by
more than half for similar years. The preferred route is partnership-based
integration for an underserved clinical segment rather than competing on sensor
hardware.

| **Scores** | TRL 8 (expected range 8–9) · overall 70.3 / 100 |
| **Sources** | 8 academic papers · 8 patents · 7 market sources |

**Headline finding:** A commercially mature platform market led by one incumbent
with an estimated 60–65% installed base, now facing cleared and funded
challengers; the patents in the registry cluster in orthopaedic and ophthalmic

### [Space-based solar power](space-based-solar-power.md)

| | |
|---|---|
| **Topic** | space-based solar power (2026-11-08, `deepseek-v4-pro`) |
| **Scores** | TRL 5 (expected range 3–5) · overall 49.6 / 100 |
| **Sources** | 8 academic papers · 8 patents · 7 market sources |

**Headline finding:** No end-to-end system validated in orbit; transmission
efficiency, kilometre-scale assembly and thermal management open. The report
names the weakness of its own market evidence: five of seven market sources
are one micro-cap company's releases, and two are the same release under two
addresses. A low-score example of what the scorecard looks like when the
evidence is thin.
